# 📱 Perfil do Usuário - Kotlin + Room

Aplicativo Android desenvolvido em Kotlin utilizando Room Database para persistência de dados locais.

## ✅ Funcionalidades

- Cadastro de usuário
- Login
- Visualização de perfil
- Atualização de dados
- Exclusão de conta

## 📌 Dados do Usuário

- Nome
- Email
- Senha
- WhatsApp
- Endereço

## 🚀 Tecnologias Utilizadas

- Kotlin
- Android Studio
- Room Database
- ViewBinding
- XML

## 🗄️ Persistência

Os dados são armazenados localmente utilizando Room Database.

## ▶️ Execução

1. Abrir o projeto no Android Studio  
2. Sincronizar o Gradle  
3. Executar no emulador ou celular
